# MinerPad

A launchpad idea where a coin's own activity pays for real compute, and that compute feeds value back into the coin.

## The idea

Most launchpads stop at the launch. MinerPad sketches what could come after it: a coin's trading activity rents machines, the machines do proof-of-work, and what they earn loops back to the coin. The whole design is built around one question: does the loop put back more than it spends?

## Screens

- **Board:** every coin and how its loop is doing
- **Rig:** one coin's machine, drawn live on a canvas
- **Farm:** the machines working together
- **Loop:** how the cycle works, step by step
- **Deploy:** the launch form

## Front end only

The backend, wallets and live data are not in this repo, and every address is a placeholder. This is a preview build: every coin, rig and number on screen is sample data, and nothing is deployed.

## Run it

```bash
npm install
npm run dev
```
